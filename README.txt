HOW TO OPEN THE WEBSITE
-----------------------
1. Download and extract the ZIP file.
2. Keep all files in the same folder. Do not separate the HTML pages from style.css or script.js.
3. Double-click index.html to open the website in your browser.
4. Use the navigation links to test the pages on desktop and mobile-sized browser windows.

IMPORTANT FORM LIMITATION
-------------------------
This is a static HTML website. The application and contact forms do NOT send information to a server or store applications. They prepare a draft in the visitor's default email app using mailto:. The visitor must review and press Send. If you want submissions delivered reliably without requiring the visitor's email app, connect a trusted form backend/service or build a secure server endpoint before publishing.
